## Run the Website Locally

### Running Locally

1. Clone this repository

```bash
git clone https://github.com/savwicak/detective-case
```

2. Navigate to the project folder

```bash
 cd .\detective-case\
```

3. Install node

```bash
 npm install
```

4. Run Tailwind CLI to build CSS

```bash
npx tailwindcss -i ./src/input.css -o ./src/dist/output.css --watch
```

4. Run the website using **Live Server** or open the `index.html` file.
